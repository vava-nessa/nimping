`free-coding-models` tracks a large catalog of models from 20+ active providers. You only need **one key** to start — sign up on any provider, grab a key, paste it into the TUI (`P` → Settings) or export it as an env var.

## The fastest sign-ups

The fastest providers to start with (no credit card, instant key):

- **Groq** → [console.groq.com/keys](https://console.groq.com/keys) — Llama 4, GPT-OSS, blazing fast
- **Cerebras** → [cloud.cerebras.ai](https://cloud.cerebras.ai) — the lowest latency in the whole catalog
- **NVIDIA NIM** → [build.nvidia.com](https://build.nvidia.com) - the widest free variety

## Configuring API keys

### Option 1: Interactive TUI Settings

Press **`P`** in the terminal UI to open the Provider API Key Settings screen. Keys are stored in `~/.free-coding-models.json` (the single config file). You can also use the Web Dashboard **Settings** page, which has a per-provider **Test key** button.

### Option 2: Environment variables

Export keys in your shell (`~/.zshrc` / `~/.bashrc`):

```bash
export GROQ_API_KEY="gsk_..."
export GOOGLE_API_KEY="AIzaSy..."
export CEREBRAS_API_KEY="csk_..."
export DASHSCOPE_API_KEY="sk-..."
```

The TUI reads env vars first; the daemon reads config first then falls back to env vars (background services may not inherit your shell). See [Configuration File](/docs/reference/config-file) for precedence details.

<Callout type="warning" title="Cloudflare needs two values">
Cloudflare Workers AI requires **both** `CLOUDFLARE_API_TOKEN` **and** `CLOUDFLARE_ACCOUNT_ID`. The base endpoint embeds your account ID: `https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/v1`.
</Callout>

## Health checks & quota

When you've configured a provider's API key, the continuous health probes are **authenticated and count against that provider's daily quota**. FCM protects you:

- **Auto-pauses** a provider the moment its probe gets a `429` (honors the `Retry-After` header).
- **Backs off exponentially** per failing model (30s → 1m → 2m → 5m).
- **Surfaces a footer chip** like `⏸ openrouter 14h` so you can see which providers are resting.

If you don't need authenticated probes, just leave the key empty — anonymous probes still work for liveness checks and won't burn your quota.

## Filtering by origin

```bash
# Filter models provided by Groq
free-coding-models --origin groq

# Filter models provided by NVIDIA NIM
free-coding-models --origin nvidia

# Filter models provided by Alibaba DashScope (Qwen)
free-coding-models --origin qwen
```

Control whether models without a key are shown:

```bash
free-coding-models --hide-unconfigured   # only providers you have keys for
free-coding-models --show-unconfigured   # show all catalog models
```
